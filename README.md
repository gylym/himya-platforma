# Химия білім беру платформасы

GitHub Pages frontend + Supabase Auth / PostgreSQL / Storage. Мектеп және университет курстары, оқу материалдары, тесттер, прогресс және әкімші басқаруы.

Жаңарту ретін, сыртқы қызметтерге қажетті қолжетімділікті және тексеру шектерін **[DEPLOYMENT.md](DEPLOYMENT.md)** файлынан оқыңыз.

- `/` — басты бет, соңғы және танымал материалдар.
- `/materials` — атауы/файл атауы бойынша іздеу, категория, пән, файл түрі сүзгілері.
- `/topics` — сыныптар мен оқу бағыттары, қосымша ChemBridge Lab сілтемесі.
- `/login`, `/register`, `/kabinet` — авторизация және профиль.
- `/admin` — Dashboard, қолданушылар, баптаулар, курс құрастырушы, аналитика.
- `/admin/materials`, `/admin/material/new` — материалдарды басқару және файл қосу.

Файлдың түрлері: PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX, PNG/JPEG/WEBP/GIF, MP4/WEBM, MP3/WAV, ZIP; 20 MB-қа дейін. Файлдардың атауы, сипаттамасы, пәні, категориясы, жариялану күйі жеке сақталады. PDF/сурет/медиа алдын ала қаралады; Office құжаттары жүктеліп, сәйкес қолданбада ашылады. Локалды Python серверінің PPTX viewer-і сақталған. GitHub Pages нұсқасында Python PPTX-render API орындалмайды.

## Файлдар

- `app.js` — маршруттар, оқу беттері, формалар мен оқиғалар.
- `catalog.js` — кітапхана карточкалары, сүзгілер, материал редакторы.
- `platform-utils.js` — файл тексеруі, upload progress, қателер, іздеу.
- `store.js` — Supabase және жергілікті API; сессия жаңарту; signed URL; upload rollback/reconciliation.
- `platform.css` — ортақ ашық интерфейс және адаптивті стильдер; бұрынғы оқу компоненттерінің CSS-і сақталған.
- `server.py` — жергілікті API, SQLite, файлдар, рұқсаттар, HttpOnly сессиясы.
- `supabase/migrations/202609130001_platform_repair.sql` — жаңа metadata, логин және RLS; 002 — email/рөл сәйкестігі, 003 — private storage.
- `supabase/functions/username-login/index.ts` — логинді серверде тексеріп, Supabase Auth арқылы авторизациялау.
- `.github/workflows/pages.yml` — тексерулер және тек ашық frontend файлдарын жариялау.
- `tests/` — интеграциялық, қауіпсіздік, файл/сессия және бастапқы құрылым сынақтары.

## Іске қосу

```sh
./start.sh
```

Сайт `http://127.0.0.1:4173` мекенжайында ашылады. Supabase айнымалылары болмаса, жергілікті SQLite режимі қолданылады. Бастапқы әкімші үшін `INITIAL_ADMIN_EMAIL` және `INITIAL_ADMIN_PASSWORD` орталық айнымалылары қажет. Құпиясөздерді кодта сақтамаңыз.

Өндірістік деректер мен бастапқы курстар көшірілмейді немесе өшірілмейді. Қосымша үлгі сайттан сыныппен ұйымдастыру және кезеңдік оқыту идеялары бейімделді; оның авторлық оқу контенті көшірілген жоқ.
