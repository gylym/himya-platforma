# Үздіксіз білім беру платформасы

## Іске қосу

```bash
./start.sh
```

Сайт: `http://127.0.0.1:4173`

Қосымша баптаусыз сайт толық локалды режимде жұмыс істейді. Пайдаланушылар, сессиялар, контент, прогресс, тест нәтижелері және белсенділік серверлік SQLite дерекқорында сақталады. Жүктелген файлдар `data/uploads/` бумасына жазылады.

Локалды әкімші:

- Email: `admin@chem.local`
- Құпиясөз: `Admin123!`
- Рөл: `Әкімші`

## Supabase режимі

1. Supabase CLI және Docker-үйлесімді контейнер ортасын дайындап, локалды жобаны іске қосыңыз:

```bash
supabase init
supabase start
supabase db reset
```

2. `.env.example` файлын `.env` деп көшіріп, `supabase status` көрсеткен URL және anon key мәндерін енгізіңіз.
3. `./start.sh` командасын қайта іске қосыңыз.
4. Оқушы немесе студент ретінде тіркеліңіз. Бірінші әкімшіні SQL арқылы тағайындаңыз:

```sql
update public.profiles p
set role = 'admin'
from auth.users u
where p.id = u.id and u.email = 'ADMIN_EMAIL';
```

Ашық тіркелу әкімші рөлін тағайындай алмайды. Нақты қорғаныс Supabase RLS саясаттарымен орындалады. `service_role` кілтін клиентке немесе `.env` файлына енгізбеңіз.

## Контент және аналитика

Әкімші әр бөлімге мыналарды қоса алады:

- шрифт, өлшем, тақырып, қалың, курсив, асты сызылған мәтін және тізімдері бар форматталған контент;
- бейне сілтемесі;
- сурет, PDF, Office құжаты, архив, аудио немесе бейне файлы;
- төрт жауап нұсқасы бар бірнеше тест сұрағы және әр сұрақтың дұрыс жауабы.

PDF файлдары бөлім бетінде тікелей алдын ала көрінеді. Суреттер мен мультимедиа превью арқылы, Word, PowerPoint және Excel файлдары атауы, түрі мен көлемі көрсетілген визуалды карточка арқылы беріледі. Бірнеше файлды бір таңдаумен жүктеуге болады.

Файл карточкасындағы «Көру» батырмасы толық визуалды терезе ашады. Терезеден файлды жаңа бетте ашуға немесе жүктеп алуға болады. PPTX презентациясының барлық слайды сайттың өз viewer-інде ретімен көрсетіліп, төмен-жоғары жылжытылады. YouTube сілтемелері бөлім бетінің ішінде шағын плеер арқылы көрсетіледі.

Әкімші панеліндегі «Дизайн» бөлімінде сайт атауы, негізгі және тақырып шрифті, мәтін/тақырып масштабы, толық палитра, сайт ені, аралықтар, контент тығыздығы, header, hero, карточка, басты бет торы, фон, көлеңке және анимация басқарылады. Нақты live preview көрсетіледі; жарияланған өзгерістер серверде сақталып, барлық пайдаланушыға қолданылады.

Бір файлдың максималды көлемі — 20 MB.

Оқушы немесе студент бөлімді ашқанда қаралым саны мен соңғы белсенділік автоматты түрде сақталады. Жеке кабинетте оқу пайызы, аяқталған бөлімдер және тест нәтижелері көрсетіледі. Әкімші панеліндегі «Аналитика» бөлімінде барлық пайдаланушының орташа прогресі, тест көрсеткіші, аяқталған бөлімдері және бөлімдер бойынша белсенділігі көрінеді.

Тест тапсырылғаннан кейін сабақ автоматты түрде аяқталған болып белгіленеді. Соңғы таңдалған жауаптар, дұрыс және қате жауап саны, нәтиже пайызы, тапсыру саны мен уақыты сақталады. Дұрыс жауап жасыл, қате таңдалған жауап қызыл күйде көрсетіледі. Осы мәліметтер оқушының/студенттің жеке кабинетінде, білім картасында және әкімші аналитикасында бірдей көрсетіледі.

Оқу архитектурасы LMS моделіне негізделген: бағдарлама → курс → модуль → сабақ. Әкімші панеліндегі «Курс құрастырушы» деңгейлерді өлшемі, түсі және тармақ сызықтары арқылы анық көрсетеді. Тармақтарды ашып/жабуға, бір деңгейдегі блоктарды ⠿ белгісінен mouse-пен жоғары-төмен сүйреуге немесе пернетақтаға арналған әрекеттермен жылжытуға болады. Рет серверде бір атомар операциямен сақталады. Контекстік қосу батырмасы қажетті деңгейді өзі таңдайды; URL, тип және сандық реттілік «Қосымша баптаулар» ішінде жасырылған. Редактор «Негізгі мәлімет», «Сабақ материалы», «Тест» және «Файлдар» атты түсінікті қадамдарға бөлінген.

Әр бөлімде «Оқу курсы» немесе «Құжаттар жинағы» форматын таңдауға болады. «Оқу бағдарламасы» мен «Силлабус» бастапқыда құжаттық режимде ашылады: оларда модуль/сабақ құрылымы көрсетілмейді, әкімші файлдарды тікелей жүктейді. PDF, Word, PowerPoint, сурет және басқа материалдар визуалды карточкаларда көрсетіліп, viewer арқылы ашылады және жүктеп алынады.

Оқушы немесе студент курс бетінде модульдерді және жалпы прогресті көреді. Сабақ бетінде курс мазмұны сол жақ панельде тұрады, алдыңғы/келесі сабақ навигациясы бар. Білім картасында әр сабақтың прогресі, аяқталу күйі және тест ұпайы сол пайдаланушының сақталған нәтижелерімен байланысып көрсетіледі.

Локалды мәліметтердің резервтік көшірмесі үшін `data/chemistry.db` файлын және `data/uploads/` бумасын бірге сақтаңыз.

## Құрылым

- `index.html` — қолданба қабығы
- `app.js` — маршруттар, беттер және интерфейс логикасы
- `store.js` — локалды және Supabase деректер қабаты
- `data.js` — бастапқы контент
- `styles.css`, `components.css`, `accessibility.css` — дизайн және адаптивтілік
- `server.py`, `start.sh` — бір командамен іске қосу
- `data/chemistry.db` — іске қосылғаннан кейін жасалатын локалды дерекқор
- `supabase/migrations/202608220001_initial.sql` — кестелер, рөлдер және RLS
- `supabase/migrations/202608220002_learning.sql` — файлдар, прогресс, тест нәтижелері және аналитика
- `supabase/migrations/202608220003_site_settings.sql` — әкімші басқаратын сайт дизайны
- `supabase/migrations/202608220004_lms_structure.sql` — курс, модуль және сабақ иерархиясы
- `supabase/migrations/202608220005_admin_reorder.sql` — блоктарды атомар реттеу функциясы
- `supabase/migrations/202608220006_quiz_insights.sql` — тест жауаптары, әрекет саны және нәтижені сақтау
- `supabase/migrations/202608220007_content_modes.sql` — оқу курсы және құжаттар жинағы режимдері
- `supabase/seed.sql` — бастапқы контент

Барлық ішкі маршруттар тікелей URL арқылы ашылады; Back/Forward тарихы SPA маршрутизациясы арқылы сақталады.

## Клиентке жариялау: GitHub + Render

Жоба түбіріндегі `render.yaml` Python web service, Frankfurt аймағы және 1 GB тұрақты диск конфигурациясын дайындайды. SQLite дерекқоры мен жүктелген файлдар `/var/data` ішінде сақталады. Render-дегі persistent disk үшін ақылы `starter` web service қажет.

1. Осы жобаны GitHub-тағы `gylym/himya-platforma` репозиторийіне жіберіңіз.
2. Render Dashboard → **New → Blueprint** тармағын ашып, `gylym/himya-platforma` репозиторийін таңдаңыз.
3. Blueprint сұраған құпия айнымалыларды енгізіңіз:
   - `INITIAL_ADMIN_EMAIL` — өндірістік әкімші email-і;
   - `INITIAL_ADMIN_PASSWORD` — кемінде 8 таңбалы бірегей құпиясөз.
4. Жоспар мен persistent disk құнын тексеріп, содан кейін ғана **Apply** басыңыз.
5. Deploy аяқталған соң Render берген `https://himya-platforma-....onrender.com` мекенжайын ашып, әкімші логинін және файл жүктеуді тексеріңіз.

`data/` бумасы GitHub-қа жіберілмейді. Сондықтан локалды тест пайдаланушылары, парольдері, прогресс нәтижелері және жүктелген файлдары жарияланбайды. Өндірістік сервер алғаш ашылғанда таза дерекқор мен бастапқы контентті өзі жасайды.
